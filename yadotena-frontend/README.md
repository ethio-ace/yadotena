# Yadotena Frontend

Restaurant and shop operations platform built with Next.js 14.

## Features
- Role-based dashboards (Owner, Manager, Waiter, Chef)
- Menu ordering system
- Retail sales processing
- Kitchen display system
- Payment management

## Quick Start
```bash
npm install
npm run dev
```

## Structure
- `/app/login` - Authentication
- `/app/owner/*` - Owner views
- `/app/manager/*` - Manager views  
- `/app/waiter/*` - Waiter views
- `/app/chef/*` - Chef views

## Tech Stack
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Zustand (state)
- Axios (API)
